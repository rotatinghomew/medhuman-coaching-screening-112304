# 模拟沟通支持筛查的处理偏差与转介额度

九轮模拟会谈的邀约、辅导历史、成绩和预约冲突记录。 数据不含真实学生、患者或就诊记录。数据表在 `data/`，业务字段和交换约定见 [资料口径](data-contract.md)。

在 Python 3.11 下可直接清点资料和检查表结构。统计环境使用 `requirements.txt` 中锁定的版本，可在虚拟环境中一次安装后离线使用。

```sh
python3 -m pip install -r requirements.txt
python3 inspect_bundle.py data
python3 -m unittest discover -s tests -v
```

资料检查入口只读，输出每张表的记录数，读取到不符合清单的表时退出。空白字段按资料口径解释。

## 分析与排班

`support_ops/` 在清点之外做三件事：按可见时点更新筛查证据、核验额外辅导收益、按结果排班。输出为教务与协调员报告：

```sh
python3 -m support_ops.cli data --wave 9 \
    --initial-at 2026-11-13T12:00:00+08:00 \
    --recheck-at 2026-11-14T09:00:00+08:00
```

加 `--format json` 输出机读版本。报告包含：

- **当时通常做法下的后测风险**：只用未受邀约学员，避免把辅导带来的改善混进风险标签。
- **额外辅导收益**：邀请意向（ITT）与完成者额外收益（CACE），仅在随机邀约的成熟轮次上估计，并给出 95% 区间；不能估计时写明原因。
- **实际领取不等于被分配**：一阶段、完成率与朴素差值并排展示，说明为什么实际领取者的差值不能当收益。
- **缺失与未成熟后测**：区分“未到期”“同教练复评”和“已到期缺失”，不把缺失当成成功；给出极端边界。
- **从未被允许选择的区间**：P0 的规则限制与 P1/P2 的邀约概率各自说明，方式对比不被当作随机。
- **筛查回放、模型比较、标签偏差与扩窗可信范围检查**：每轮只用此前成熟对照训练，再用当轮对照检查。
- **轮转 × 练习能力的可用性**：列出人数、区间与宽度；证据不足的组合写明无法给出收益优先级。
- **排班方案**：全体名额与最低覆盖两案，逐条说明依据“收益证据”还是“保障规则”；保留已确认场次，整段训练不拆分，申请中的场次不占座。
- **复核改判的两个阶段**：第一阶段与第二阶段各自可见的记录、保留的已确认场次与需明确确认的调整。
- **本轮回看**：名单对照实际辅导与未成熟后测，标出阶段变化。
- **下一轮可带走的证据状态**：哪些轮次成熟、哪些轮转或能力段仍缺对照。

模块划分：`bundle.py` 读取与按时点截取，`cohort.py` 组织记录，`effects.py` 估计收益与缺失，`screening.py` 回放与模型比较，`schedule.py` 排班，`audit.py` 轮次回看，`report.py` 生成报告，`cli.py` 命令行入口。
